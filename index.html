Personal-use OAuth application

PKS-rclone

PKS-rclone は、個人の知識管理システム（Personal Knowledge System、PKS）のファイルを、Ubuntu PC と本人の Google Drive の間で同期するための、個人利用向け OAuth アプリです。

アプリの機能

  • オープンソースの同期ツール rclone を使用して、Markdownなどのファイルを双方向に同期します。
  • 本人の許可を得て Google Drive API にアクセスし、同期に必要なファイルの一覧取得、読み取り、作成、更新、削除を行います。
  • OAuth認証は本人のGoogleアカウントで行います。この公開Webページ自体にGoogleログイン機能はありません。

利用対象

開発者本人の個人利用を目的としています。第三者に提供する同期サービスではありません。また、このページからPKSのファイルを公開・配布することはありません。

データの取り扱い

アクセスするGoogle Driveデータの目的と管理方法は、プライバシーポリシーに記載しています。
